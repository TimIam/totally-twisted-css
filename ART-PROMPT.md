# Generated artwork

Method: built-in OpenAI image generator. The tool does not expose a model selector; no claim is made that this used a model called GPT Image 2.5.

Saved asset: `assets/twisted-sprites.png` (1254 × 1254 PNG, transparent). The app maps it to a 1280 × 1280 logical atlas, selecting sixteen 320 × 320 logical cells without modifying the generated file.
