## After Dark in CSS

Source: https://github.com/bryanbraun/after-dark-css

Upstream commit: `20630dba51d49101dba0b52205400d31be9c0c37`

The upstream README licenses its HTML and CSS under the MIT License. Copyright (c) Bryan Braun and contributors. The original README is preserved at `upstream/README.md`.

This project reuses and adapts the Flying Toasters and Fish HTML/CSS for its Flying Toilets and Toxic Swamp scenes. Its git history comes from the upstream clone. Adaptations include selector scoping, adjustable speeds, new sprite artwork, and removal of the old sprite-frame animation.

The original repository's Berkeley Systems images and ChicagoFLF font are not included in this working tree or loaded by the app. They remain in the publicly available upstream git history. Their original licenses and copyrights still apply there; the MIT code license does not relicense those assets.

Upstream credits Jonathon Sampson, Keith Clark, Rob Glazebrook, and Ryan Justice for CSS tutorials and demos, and N. Landsteiner, David Donarumo, and Lazy Game Reviews for preservation work. See the preserved README for links.
